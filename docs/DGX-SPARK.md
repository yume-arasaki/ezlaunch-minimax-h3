## Detection reality (important)

`nvidia-smi --query-gpu=name,compute_cap,memory.total` on GB10 returns:

```
NVIDIA GB10, 12.1, 128 GB        # compute_cap 12.1 = SM121 (≠ SM100/89!)
```

- **Memory shows "Not Supported"** — unified memory, no dedicated VRAM.
  Use `free` / `top` / DGX Dashboard (https://localhost:11000).
- SM121 needs **CUDA 13 builds** (vLLM requires `cu130-nightly`). Many kernels
  don't support SM121 yet.
- EZlaunch detection name-locks on `"GB10"` and skips the VRAM path entirely.
- Driver ≥ 580 (CUDA 13).

## Node graph (the correct AV path)

1. `UNETLoader` → pruned int8 base, `weight_dtype: default`
2. `MiniMaxH3SigmaShift` → `shift_video 12.0`, `shift_audio 3.0`
3. `CLIPLoader` → Heretic NVFP4 TE, `type: minimax`
4. `VAELoader` (video) + `VAELoader` (audio)
5. **`MiniMaxH3ReferenceToVideo`** (NOT ImageToVideo) — width 384, height 672,
   `length 362` (~15.08s @ 24fps), `ref_image_size: match`
6. `ConditioningZeroOut` for negative conditioning
7. `KSampler` → `res_multistep`, `simple`, **cfg 1.0, steps 20** (10 was patchier)
8. `VAEDecode` (video) + `VAEDecodeAudio` (audio)
9. `CreateVideo` → fps 24, bit_depth 8
10. `SaveVideo` → mp4, h264

Verified output: 384x672 / 24fps / 362 frames / ~15.08s, aac audio, ~1.0MB.

## Recursion: these apply to ALL tiers, confirmed again on Spark

- Frame count **17n+5** (362 = 15.08s ✓) — see `scripts/` for the validator hook
- `--disable-pinned-memory --fp16-intermediates expandable_segments` baked in
- `memory_usage_factor` 0.114 → 1.0 patch (EZlaunch does this on install/launch)
- res_multistep via BasicGuider; **KSamplerSelect alone = IndexError**
- `VAEDecodeTiled` is a no-op / fails on nested H3 latents — use plain `VAEDecode`

## Non-negotiables on Spark

| Rule | Why / source |
|---|---|
| **Never** `--use-sage-attention` with H3 | mosaic / wrong path on GB10 (drowzeys, bjarkebolding) |
| SageAttention pinned **pre-3.0** | 3.x = mosaic artifacts on GB10 commit d1a57a54 (bjarkebolding) |
| `swap off`, `swappiness 10`, driver persistence | spark-comfyui |
| `/dev/shm ≥ 16g` | spark-comfyui |
| Sol-Attn flex_attention on sm_121 = **silently wrong** (cos sim 0.92–0.97 vs SDPA) | drowzeys |
| H3 blocks mutate input in place → need 2x `.clone()` | drowzeys |
| cache threshold assumes 50 steps | drowzeys |
| Never benchmark a busy GB10 | drowzeys |
| Co-tenancy: start LLM first, H3 after; restarting LLM → stop H3 first | our hardware compile |
